Topics
¡Network applications
 ¡ How common Internet applications work (e.g., web, peer-to-
   peer applications, DNS, video streaming)
 ¡ How to build applications that span multiple computers and
   use Internet to communicate


¡Network communication protocols
 ¡ Transport protocols (how to deliver message across Internet),
   network layer (how to send data from source to destination),
   and link layer (medium access control), physical layers


¡Advanced topics
 ¡ Data center networking, software-defined networking
