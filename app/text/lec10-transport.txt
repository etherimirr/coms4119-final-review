Consistent Hashing
§ A special type of hashing: when the hash table is resized, the number
  of keys that need to be remapped is bounded

§ Minimize the number of objects/items that need to be moved when
  a node leaves/joins the network

§ All DHTs implement consistent hashing

Comments
§ A very popular research topic in networking and systems
  • Representative systems: Chord, CAN, Tapestry, Pastry…
§ Used in practical systems such as BitTorrent, emule, blockchains,
  distributed file storage systems
§ Nice system properties
  • Scalability, low latency, load balancing, dynamic configuration, resilience


§ Not really used by Google searches or Facebook newsfeed, why?
  • Hard to handle intersection queries, sophisticated ranking, aggregation
  • Big companies prioritize centralized control with predictable latency and fast
    recovery, but they use DHT-like techniques internally

Summary
§ Multiplexing, demultiplexing: based on segment, datagram
  header field values
§ UDP: demultiplexing using destination port number (only)
§ TCP: demultiplexing using 4-tuple: source and destination IP
  addresses, and port numbers
§ Multiplexing/demultiplexing happen at all layers
