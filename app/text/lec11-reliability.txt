Quiz
Your host are sending a message of 10 packets of 0.012Mb each to a
server. See the topology and link bandwidth numbers as below:
                   6Mbps                6Mbps

We assume a negligible latency or propagation delay. The router uses
store-and-forward transmission. How long would it take for the server
to receive all 10 packets?
Answer: Each packet needs 0.012/6 = 2ms to be transmitted over a
link. The router can send a packet to the server while your host sends
the next. Think of the 10-th packet, it’ll take 2ms * 10 = 20ms for the
host to send out this last packet, which will need another 2ms for the
router to send it to the sever. Thus, in total 20ms + 2ms = 22ms.
