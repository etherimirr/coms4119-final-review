     c) (3 points) the host part of this address,

5) (10 points) When two users behind the same NAT router access the same website on a web server, suppose
   the NAT router only has one public IP address, explain how the web server can distinguish requests from the
   two users, and how the web server’s responses are sent back to different users.
   Answer: From the web server’s point of view, the two users’ requests will carry the same public IP address,
   but from different source port numbers (assigned by the NAT router). The web server’s responses will carry
   different destination port numbers, one for each client. The NAT router will forward the responses to the
   corresponding clients by looking up its NAT table.
