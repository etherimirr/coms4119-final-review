     Efficiency of Slotted ALOHA
30


     ¨   Suppose N nodes have packets to send
         ¤ Each transmits in a slot with probability p


     ¨   Probability of successful transmission:
             by a particular node i: Si = p (1-p)(N-1)
             by any of N nodes:         S= N p (1-p)(N-1)
     ¨   What value of p maximizes the prob. of success:
         ¤ For fixed p, S à 0 as N increases

         ¤ But if p = 1/N, then S à 1/e = 0.37 as N increases


     ¨   Max efficiency is only slightly greater than 1/3!

     Key Ideas of Random Access
38


     ¨   Carrier sense
         ¤ Listen before speaking, and do not interrupt

         ¤ Checking if someone else is already sending data, wait
           till the other node is done
     ¨   Collision detection

     ¨   Randomness (Collision recovery)
         ¤ Do not start talking again right away
