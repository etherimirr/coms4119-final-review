性能指标

  • 传输时间 = L/R（包大小/带宽）
  • 传播延迟 = d/v（距离/光速 3·10⁸m/s；声速 1.5km/s）
  • 队列/处理延迟：可忽略除非题目给
  • 端到端 1 包：Σ(每段 L/R + d/v) + queuing
  • 串联多段 + N 包 pipelined：第一个跑完所有段 + (N−1) × 瓶颈段 L/R
  • BDP = bandwidth × RTT = "管道里能塞多少 bit"
  • Throughput = min(各段带宽)（瓶颈）

HTTP RTT 计数 考

  • 非持久：每对象 1 RTT 建连 + 1 RTT GET = 2 RTT/obj
  • 持久 + pipelined：base 2 RTT；同层 inline 共 1 RTT；嵌套依赖 +1 RTT/层
  • 持久 无 pipelined：每对象顺序 1 RTT
  • web cache（proxy）减小 RTT/带宽，引入一致性问题

DNS

  • 层级：root → TLD(.com,.edu) → authoritative
  • 递归 vs 迭代解析；local resolver 通常迭代
  • RR 类型：A（IPv4）、AAAA（IPv6）、NS、MX、CNAME
  • UDP 53，简短查询；大响应回退 TCP

P2P 文件分发 期中Q7

CS: T = max(NF/U_s, F/d_min)
P2P: T = max(F/U_s, F/d_min, NF/(U_s+ΣU_i))
  • F=文件大小，N=客户数，U_s=server 上传，d_min=最慢下行，U_i=peer 上传
  • BitTorrent：tit-for-tat（rarest first 选块；optimistic unchoke）
  • DHT：分布式哈希表查找资源 owner

Stop-and-Wait Utilization

U = T_trans / (T_trans + 2·T_prop)
  • T_trans = L/R
  • 当 L 小或距离远 → U 很低 → 必须用滑窗

TCP 段格式

  • 源/目的 port（16b）、seq、ACK#（32b）
  • flags：SYN、FIN、ACK、PSH、URG、RST、CWR/ECE（ECN）
  • rwnd（receiver buffer 余量）→ 流控
  • checksum 校验头+数据

TCP 拥塞控制 FSM 考点

  • slow start：cwnd=1，每 ACK cwnd+=1 MSS（每 RTT 翻倍）
  • 到 cwnd > ssthresh → congestion avoid（每 RTT +1）
  • 3 dup ACK → ssthresh=cwnd/2，cwnd=ssthresh+3 → fast recovery；new ACK → 回 CA（cwnd=ssthresh）
  • Timeout（任何状态）→ ssthresh=cwnd/2，cwnd=1，回 slow start

AIMD 公平性 几何

  • +a 走 45°（同时加），×b 沿原点缩（保比例）→ 螺旋收敛到 x1=x2
  • 四种组合：只 AIMD 同时收敛公平+效率
  • 前提：相同 RTT、长 CA、session 数不变
throughput ≈ cwnd/RTT；avg cwnd = 3W/4 → R = 3W/(4·RTT)

拥塞控制变种

  • CUBIC（Linux 默认）：W(t)=C(t−K)³+Wmax，远离 Wmax 增长快
  • Delay-based：用 RTT 升判拥塞；和 loss-based 共存会 starve
  • BBR（Google）：估 bottleneck BW + RTprop，inflight=BDP
  • ECN：路由器在 IP ToS 打 2 bit；receiver 经 ACK ECE=1 回传；sender 不丢包就减半

UDP 不公平 / 并行 TCP

  • UDP 无 CC → 任意抢带宽
  • 开 K 条并行 TCP → 自己得 K/(K+他) 份额
  • 没有 "Internet 警察"

Network 数据面 vs 控制面

  • Data plane：单 router 内、ns 级、forwarding
  • Control plane：全网、ms 级、routing
  • 传统：每 router 跑 routing 算法 → 自己填 FT
  • SDN：远程 controller 算好 FT 下发

  • 速度：fabric N×R 才能跑满 N 输入

Dijkstra 模板

  1. N'={u}；D(v)=c(u,v) 或 ∞
  2. 循环：取不在 N' 中、D 最小的 w 加入 N'
  3. 对 w 的每个邻居 v 不在 N'：D(v)=min(D(v), D(w)+c(w,v))
  4. 直到 N' 包含全部节点

复杂度 O(n²)；可优化 O(n log n)。给 6 节点表必练手算。

Bellman-Ford / DV

D_x(y) = min_v∈N(x) { c(x,v) + D_v(y) }
  • 每节点维护 distance table（行=目的，列=经哪个邻居）
  • DV = 表按行取 min
  • 邻居发 DV → 自己 BF 更新 → DV 变了告诉邻居
  • 收敛轮数 ≈ 最短路径树最大跳数 − 1（同步、无 CTI、静态）

Count-to-Infinity 与对策

  • 链路涨价 → 坏消息慢传 → 两节点互推累加
  • Poison reverse：z 经 y 到 X → z 告诉 y 自己到 X 是 ∞
  • 只解 2 节点环，>2 仍可成环
  • RIP：DV 每 30s 一次；hop limit 16=∞

OSPF（intra-AS）

  • Open；Link State；flood LSA（直接走 IP，不用 TCP/UDP）
  • 跑 Dijkstra，权重可多指标（BW/delay）
  • 消息认证
  • 分层：local area + backbone；ABR 汇总；boundary router 连其他 AS

BGP（inter-AS）FinalQ3

  • eBGP：跨 AS 邻居；iBGP：AS 内传 eBGP 信息
  • TCP 上跑；OPEN/UPDATE/KEEPALIVE/NOTIFICATION
  • advertise：(prefix, AS-PATH, NEXT-HOP)
  • 路径选择：local pref → shortest AS-PATH → closest NEXT-HOP (hot potato) → others
  • Policy：export/import 决定 advertise/accept；ISP 不愿替别人 carry 过境流量
  • Hot potato：选 intra-AS 最便宜的 gateway 扔出

SDN + OpenFlow

  • Controller 算 FT 下发到 switches
  • Match + Action 抽象：match (link/net/trans 各字段)；action drop / forward / modify / to-controller
  • Priority 解决重叠；counter 统计
  • controller→switch：features/configure/modify-state/packet-out
  • switch→controller：packet-in/flow-removed/port status
  • 抽象统一：router/firewall/switch/NAT 都能 match+action 表达

Data Link 概览

差错检测

  • Parity：1 bit，只检奇数错；2D parity 检+纠 1 bit
  • Checksum：16-bit 字累加（TCP/UDP/IP 用）
  • CRC：D·2^r mod G = R；发 (D,R)；接收 (D·2^r XOR R) mod G==0？

CRC 模 2 = XOR；能检测所有 ≤r 位突发错

Slotted ALOHA

  • 每 slot 各以 p 发；碰了下 slot 再 p 重试
  • P(单 i 成功)= p(1−p)^(N−1)；总 S=Np(1−p)^(N−1)
  • p*=1/N → S → 1/e ≈ 0.37
  • Pure ALOHA（不对齐）→ 1/(2e) ≈ 0.18

CSMA / CD

  • CS：先听，闲再发
  • 仍会碰（传播延迟）→ 边发边听 → 碰了 abort + jam + 退避
  • min frame ≥ 2 × max prop delay（不然发完才察觉碰撞）
  • 10Mbps Ethernet：min 512b，max cable 100m
  • Binary exponential backoff：碰 n 次，从 [0, 2^n−1] 选

Ethernet 帧

  • Preamble 7B + SFD 1B
  • Dst MAC 6B + Src MAC 6B
  • Type 2B（0x0800=IP, 0x0806=ARP）
  • Payload 46–1500B
  • CRC 4B
  • 现代 Ethernet = switched，全双工、无 CSMA/CD

MAC Address & ARP

  • MAC 6B；前 3B = OUI（厂商）；广播 FF×6
  • OS 可改（MAC spoofing）
  • ARP：知 IP 找 MAC；广播 query、unicast reply；缓存带 TTL（soft state）
  • 跨子网：ARP 找 first-hop router 的 MAC，不是终点

Switch（L2）

  • 自学习：见 frame → 记 (src MAC, in-port, TTL)
  • Dst 在表 → 单口发；不在 → flood
  • Plug-and-play；不动 TTL；不解 IP
  • VLAN：物理 switch 分逻辑 LAN；跨 VLAN 需 router

无线物理

Loss = (4πd/λ)² = (4πdf/c)²
  • f 大（λ 小）→ loss 大（5GHz 衰更快）
  • real：PL=PL₀ + 10α·log(d/d₀) + X；α 室内 4–6
  • SNR dB = 10·log(signal/noise)；SINR 加干扰
  • SNR↑ → BER↓ → 可用高 modulation/code rate
  • 传播：反射（>λ 表面）、衍射（锐边）、散射（<λ 物体）
  • Multipath fading：ISI，限 symbol rate

隐藏/暴露终端 FinalQ5

  • Hidden：在 sender 范围外，但在 receiver 干扰范围内 → 不知道，发了 → receiver 碰撞
  • Exposed：在 sender 范围内（听到），但自己的目标在 sender 范围外 → 白白抑制
  • RTS/CTS：sender 发 RTS，receiver 回 CTS（带 NAV）；听 CTS 者静默 → 治隐藏；不能治暴露

CSMA/CA (802.11) 完整流程

  1. 载波感知（物理：能量；虚拟：NAV）
  2. 信道闲 → 等 DIFS → 仍闲 → 发 RTS / 数据
  3. 回复（CTS/ACK）等 SIFS（短、优先）
  4. 信道忙 → DIFS 后启 random backoff，倒数 [0,CW]
  5. 信道再忙就冻结，闲再减；到 0 发 RTS
  6. RTS 没 CTS → CW × 2（binary exp backoff，到 CWmax）
  7. 成功 → 复位 CW=CWmin

无线不能 CD：发时自己耳朵被淹

易错点汇总

  • 丢包 ≠ 拥塞（无线 bit error / checksum 失败 → silently drop）
  • Stop-and-wait U 公式分母是 2·T_prop，单程要乘 2
  • 子网计算用二进制 AND 心算别用十进制减
  • BGP 政策：控制别人能不能借道你 → export policy 不 advertise
  • Fast recovery 收 new ACK 是回 CA（cwnd=ssthresh），不是 slow start
  • min Ethernet frame 不是任意值，由 2×prop 决定
  • 隐藏/暴露：隐藏 = sender 外 receiver 内；暴露 = sender 内自己目标外
