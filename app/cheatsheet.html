COMS 4119 FINAL CHEAT SHEET — APP + TRANSPORT

Delays & Performance

  • Transmission = L/R (size/bandwidth)
  • Propagation = d/v (light 3·10⁸ m/s, sound 1.5 km/s)
  • Queuing: depends on load
  • End-to-end = Σ(L/R + d/v) per link + queue
  • Pipelined N pkts: 1st full path + (N−1)·bottleneck tx time
  • BDP = R · RTT (bits in pipe)
  • Throughput = min(per-link R) = bottleneck

Stop-and-Wait Utilization

U = T_trans / (T_trans + 2·T_prop)
  • T_trans = L/R
  • When L small or distance long → U collapses → need sliding window
  • Mid: 2 Kb @ 40 Kbps over 30 m acoustic + 3 km air → U≈0.54; @ 200 b → 0.11. Not good.

Layering

  • L7 App (HTTP/DNS) ↔ L4 (TCP/UDP) ↔ L3 (IP) ↔ L2 (Eth/802.11) ↔ L1
  • Each layer adds its own header (encapsulation)
  • Demux by port (L4), IP proto (L3), Ethertype (L2)

HTTP RTTs exam

  • Non-persistent: each obj = 1 RTT TCP + 1 RTT GET = 2 RTT/obj
  • Persistent + pipelined: base 2 RTT; same-layer inline 1 RTT; each nesting +1 RTT
  • Persistent no pipeline: each obj 1 RTT sequentially
  • Web cache (proxy): cuts RTT/BW but adds consistency issues
  • Mid Q1 example: HTML + 4 jpg + 1 css(2 jpg) → 2 + 1 + 1 = 4 RTT

Sockets (Q1 trap)

  • UDP server: 1 socket only (no connection)
  • TCP server: 1 welcome + N connection = N+1
  • Distinguish clients by (src IP, port) in UDP datagram

DNS

  • Hierarchy: local → root → TLD(.com,.edu) → authoritative
  • Recursive vs iterative resolution; local usually iterative
  • RR: A (IPv4), AAAA (IPv6), NS, MX, CNAME
  • UDP 53 short, falls back to TCP for large

P2P file distribution exam

CS: T = max(NF/U_s, F/d_min)
P2P: T = max(F/U_s, F/d_min, NF/(U_s + ΣU_i))
  • BitTorrent: tit-for-tat + rarest-first + optimistic unchoke
  • DHT: distributed hash for resource lookup
  • P2P beats CS when N grows (server upload not multiplied)

Video / DASH

  • Chunks at multiple bitrates
  • Client adapts based on observed BW
  • HTTP-based; can use any CDN

TCP Segment Format

  • src/dst port (16 b each)
  • seq# / ACK# (32 b each)
  • flags: SYN, FIN, ACK, RST, PSH, URG, CWR/ECE (ECN)
  • rwnd (receiver buffer free) → flow control
  • checksum (header + payload)

3-Way Handshake

  1. Client → SYN, seq=x
  2. Server → SYN-ACK, seq=y, ack=x+1
  3. Client → ACK, seq=x+1, ack=y+1

Connection close = 4-way (FIN/ACK each direction).

SR window ≤ N/2 (seq space ambiguity).

TCP cwnd

  • Sender: LastByteSent − LastByteAcked < cwnd
  • rate ≈ cwnd / RTT bytes/sec
  • inflight ≤ min(cwnd, rwnd)
throughput ≈ cwnd / RTT

TCP CC FSM exam

  • Slow start: cwnd=1; each ACK cwnd += MSS (×2/RTT)
  • cwnd > ssthresh → Congestion avoidance (+1 MSS/RTT)
  • 3 dup ACKs in CA → ssthresh=cwnd/2, cwnd=ssthresh+3 → Fast recovery; new ACK → back to CA (cwnd=ssthresh)
  • Timeout any state → ssthresh=cwnd/2, cwnd=1 → slow start

Trap: FR + new ACK → CA, NOT slow start.

AIMD Fairness exam

  • +a moves both up 45° (efficiency line)
  • ×b scales toward origin (keeps ratio)
  • Spiral converges to x1=x2 ∩ x1+x2=1
  • Only AIMD achieves both fairness and efficiency
avg cwnd = 3W/4 ⇒ R = 3W/(4·RTT)

CC variants

  • CUBIC (Linux default): W(t) = C(t−K)³ + Wmax. Fast climb back to Wmax, slow probe past.
  • Delay-based (Vegas): detect via rising RTT; starves alongside loss-based
  • BBR (Google): model BtlBw + RTprop, inflight = BDP
  • ECN: router marks IP ToS 2 bits at queue threshold; rcvr ACK ECE=1; sender halves cwnd, no drop

Fairness traps

  • UDP doesn't CC → grabs unfair share
  • K parallel TCPs → app gets K/(K+others)
  • Different RTTs → shorter RTT wins
  • "No Internet police"

Router Architecture

  • Input ports: link, lookup (LPM), queue
  • Switch fabric: memory / bus / interconnection (Crossbar, Clos)
  • Output ports: queue, scheduler, link
  • HOL blocking: head-of-line stuck → rest waits. Fix: VOQ

Scheduling

  • FCFS/FIFO: order of arrival
  • Priority: classes by header; high first; FCFS within
  • RR: rotate one packet per class per round
  • WFQ: class i gets w_i/Σw_j share → min-BW guarantee

Buffer Mgmt

  • Drop: tail / priority
  • Mark: ECN, RED (early detect)

IPv4 Datagram

  • ver(4) | hlen(4) | ToS(8, ECN low 2 b) | total len(16)
  • id | flags(3) | frag offset(13) → fragmentation
  • TTL(8): −1/hop, 0 → drop (prevents loops)
  • protocol(8): 6=TCP, 17=UDP
  • header checksum(16) — header only!
  • src/dst IP (32 b each)
  • options + payload. Hdr ≥20 B, max 64 KB

Longest Prefix Matching exam

  • Pick rule with longest matching prefix
  • TCAM = ternary content-addressable; O(1) lookup with wildcards
  • Mid 4-Q: 1010.1000.0100.1000 vs 1010.xxxx/4, 10xx/2, 1010.11xx/6 → matches /4 and /2, NOT /6 (10≠11) → choose /4 → port 2

CIDR & Subnet calc exam

prefix = IP AND mask; hosts = 2^(32−x)

  • Final ex: 128.16.51.2 /20 → 51 (00110011) AND 240 (11110000) = 48 → prefix 128.16.48.0/20, host 0.0.3.2, 2¹²=4096
  • Private: 10/8, 172.16/12, 192.168/16

Dijkstra (LS)

D(v) = min(D(v), D(w) + c(w,v))
  1. N'={u}; D(v)=c(u,v) or ∞
  2. pick w ∉ N' with min D(w); add to N'
  3. relax all neighbors of w
  4. repeat until N' = all nodes

O(n²); heap O(n log n). Msg complexity O(n²) too.

Bellman-Ford (DV)

D_x(y) = min_v∈N(x){ c(x,v) + D_v(y) }
  • Each node: table[dst][via neighbor]
  • DV = row-min of table
  • On neighbor DV msg → update via BF; if own DV changes → tell neighbors
  • Convergence ≈ max-hop-count in shortest-path tree − 1 (sync, static, no CTI)

Count-to-Infinity

  • Link cost ↑: stale DVs cause loops, +1/+1 spiral
  • Poison reverse: if Z routes thru Y to X, Z advertises Z→X=∞ to Y
  • Solves 2-node loops; not 3+ node loops
  • RIP hop=16 means ∞

OSPF (intra-AS)

  • Open, link-state, runs Dijkstra
  • Flood LSAs directly over IP (no TCP/UDP)
  • Multi-metric weights (BW, delay)
  • Authenticated messages
  • Hierarchy: area + backbone; ABR summarizes

BGP (inter-AS) exam

  • Path vector, advertised over TCP
  • eBGP: between ASes; iBGP: within an AS
  • Msgs: OPEN / UPDATE / KEEPALIVE / NOTIFICATION
  • Advertise = (prefix, AS-PATH, NEXT-HOP)
  • AS-PATH includes own AS → reject (loop)
  • Route select: 1) local pref 2) shortest AS-PATH 3) closest NEXT-HOP (hot potato) 4) others

BGP Policy final Q3

  • Export: choose whom to advertise to
  • Import: choose whose route to accept
  • Provider only wants to carry traffic to/from customers; refuses transit between other ISPs
  • Columbia-CERN example: don't advertise CERN path to NYU → NYU can't route via Columbia

Hot Potato Routing

  • Multi-exit to same dst → pick gateway with min intra-AS cost
  • "Throw the hot potato out fast"
  • Economics: don't carry traffic on own network longer than needed

Why Intra ≠ Inter exam

  • Policy: inter needs admin policy; intra single admin
  • Scale: hierarchy shrinks tables
  • Performance: intra optimizes path; inter optimizes policy

SDN + OpenFlow

  • Controller computes FTs, ships to switches via OpenFlow
  • Match + Action generalizes router/firewall/switch/NAT
  • Match: any L2/L3/L4 fields w/ wildcards
  • Action: forward / drop / modify / to-controller
  • Priority resolves overlaps; counters track stats
  • Msgs C→S: features, configure, modify-state, packet-out
  • Msgs S→C: packet-in, flow-removed, port-status
  • Northbound API for apps, southbound for switches

COMS 4119 FINAL CHEAT SHEET — DATA LINK

Link Layer services

  • Framing (hdr + trailer)
  • Error detection/correction
  • MAC (medium access control)
  • Reliable delivery (often skipped on low-BER)

Error Detection

  • Parity 1-bit: detects odd-bit errors only
  • 2D parity: detects + corrects single bit
  • Checksum: 16-b word sum w/o carry (TCP/UDP/IP)
  • CRC: D·2^r mod G = R; transmit (D, R); receiver checks (D·2^r XOR R) mod G == 0
R = (D · 2^r) mod G (mod 2 = XOR)

CRC detects all burst errors ≤ r bits.

CRC worked example

G=1001, D=101011, r=3:

D·2^r = 101011000
Divide mod-2 (XOR) by 1001:
   101011000
 ⊕ 1001
  --------
    011 → bring next bits
   ...
Remainder R = 110 (3 bits)
Transmit: 101011 110

Slotted ALOHA derivation

S(p) = N · p · (1−p)^(N−1)
  • Max at p* = 1/N
  • S_max → 1/e ≈ 0.37 as N → ∞
  • Pure ALOHA (no slots): collision window doubles → 1/(2e) ≈ 0.18

CSMA / CSMA-CD

  • CS: listen before send
  • Collisions still happen due to propagation delay
  • CSMA/CD (wired only): listen while sending; abort on collision; jam + binary backoff
  • Wireless can't CD: TX deafens RX

CSMA/CD min frame size exam

L_min / R ≥ 2·d_max / v
  • Need to detect collision before tx ends
  • 10 Mbps Ethernet: min 512 bit, max cable 100 m
  • Binary backoff: after n collisions, pick slot ∈ [0, 2^n − 1]

Ethernet Frame

  • Preamble 7 B + SFD 1 B (clock sync)
  • Dst MAC 6 B + Src MAC 6 B
  • Type 2 B (0x0800 IP, 0x0806 ARP)
  • Payload 46–1500 B
  • CRC 4 B

Modern Ethernet = switched, point-to-point, full duplex, no CSMA/CD.

MAC Address

  • 6 B; first 3 B = OUI (vendor)
  • Broadcast: FF:FF:FF:FF:FF:FF
  • OS can override (MAC spoofing)
  • Not used for security

ARP

  • Map IP → MAC
  • Broadcast query, unicast reply, cache with TTL
  • Cross-subnet: ARP resolves first-hop router's MAC, not the final dst
  • Host knows when to use router via netmask (from DHCP)

Switch (L2)

  • Store-and-forward at L2
  • Self-learning: on frame in, record (src MAC, in-port, TTL)
  • Dst in table → unicast; else flood
  • Plug-and-play; no config
  • Doesn't touch TTL

VLAN

  • One physical switch → multiple virtual LANs (by port or MAC)
  • Traffic isolation; dynamic port-to-VLAN reassignment
  • Cross-VLAN → must go through router

COMS 4119 FINAL CHEAT SHEET — WIRELESS

Wireless ≠ Wired exam

  1. Time-varying channel: distance, mobility, environment
  2. Broadcast → interference from neighbors

These drive all wireless MAC design.

Free-Space Pathloss

L = (4πd/λ)² = (4πd·f/c)²
  • d = distance, λ = wavelength, f = freq, c = light speed
  • Higher f (smaller λ) → more loss
  • 5 GHz attenuates faster than 2.4 GHz; worse through walls

Real env: PL(d) = PL(d₀) + 10α·log(d/d₀) + X. α=2 free; 2.7–3.5 urban; 4–6 indoor.

Propagation Modes

  • Reflection: object ≫ λ (walls, ground)
  • Diffraction: sharp edges → bends around obstacles (corners)
  • Scattering: object < λ (leaves, lamp posts) — hardest to model

Fading

  • Large-scale: average drop w/ distance (pathloss + shadowing)
  • Small-scale: rapid swings in small area (multipath interference)
  • Mobility → small-scale fade

Multipath & Coherence Time

  • LOS + reflected paths arrive at different times → ISI
  • Coherence time = duration channel response stays valid
  • Symbol period must be < coherence time

SNR / SINR

SNR_dB = 10·log₁₀(S/N); SINR_dB = 10·log₁₀(S/(N+I))
  • Higher SNR → lower BER → higher mod/code rate possible
  • SINR adds interference from other senders

WiFi ranges

  • Transmission < Interference < Carrier sensing
  • Neighbors may interfere but not decode

Hidden Terminal exam

  • X outside sender A's range, inside receiver B's interference range
  • X thinks idle → sends → collision at B
  • Symptom: A sends fine, B receives nothing
  • Fix: RTS/CTS (B's CTS quiets nodes around B)

Exposed Terminal

  • X inside sender A's range (hears A), but X's own target is outside A's range
  • X needlessly defers → wasted parallelism
  • No clean CSMA/CA fix

Mnemonic: hidden = sender-out + recv-in (should stop but doesn't). Exposed = sender-in + target-out (defers but didn't need to).

RTS / CTS / NAV

  • A sends RTS → B replies CTS (with NAV duration)
  • Nodes hearing RTS quiet for ~CTS time
  • Nodes hearing CTS quiet for full NAV
  • Solves hidden, NOT exposed

CSMA/CA full flow exam

  1. Carrier sense (physical + virtual NAV)
  2. Idle → wait DIFS → still idle → send
  3. Replies (CTS/ACK) wait SIFS (shorter; priority over new contention)
  4. Busy → after DIFS, start random backoff [0, CW]; decrement when idle, freeze when busy
  5. Backoff=0 → send RTS
  6. No CTS → CW = min(2·CW, CWmax) (binary exp)
  7. Success → reset CW = CWmin

No collision detection: TX deafens own RX.

Backoff variants

  • Binary exp: too aggressive reset → oscillation + unfair
  • MACAW: CW −1 on success (linear decrease, "AIMD" of MAC)
  • Append CW to packet so peers track congestion

COMS 4119 — EXAM PITFALLS & FORMULA INDEX

Loss ≠ Congestion final Q1

  • Bit error → checksum fail → silently dropped
  • Common in wireless
  • TCP misreads as congestion, halves cwnd
  • ECN helps by giving explicit signal

RTT counting pitfalls

  • Non-persistent: don't forget connection-setup RTT (×2 per object)
  • Nested deps (CSS → image inside CSS): +1 RTT per layer
  • Pipelining vs no-pipelining matters even in persistent

Bottleneck calc traps

  • N pkts pipelined: 1st pkt = full path; rest = (N−1)·bottleneck only
  • Store-and-forward adds tx delay at EVERY hop
  • Don't double-count propagation if asked for one-way vs round-trip

Subnet math

  • Do AND in binary, not decimal; the middle octet bites
  • Mask /x → host bits = 32 − x
  • Reserved: all-0 (network), all-1 (broadcast)

BGP policy

  • "Don't carry transit" → don't advertise external path to peer
  • Customer of provider always gets advertised
  • Hot potato = pick exit closest in intra-AS cost, ignore inter-AS hops

DV mechanical errors

  • Init: only direct neighbors filled, rest ∞ (per-via column)
  • BF takes min over neighbors, not sum
  • Count-to-infinity: bad news travels slow
  • Poison reverse only breaks 2-node loops

TCP FSM trap

  • Fast recovery + new ACK → CA (cwnd=ssthresh), not slow start
  • Timeout always → slow start (cwnd=1)
  • ssthresh updated to cwnd/2 on any loss event

Hidden vs Exposed

  • Hidden: sender's range out, receiver's interference in
  • Exposed: sender's range in, my target out of sender's range
  • RTS/CTS solves hidden; exposed has no clean fix

CSMA/CD limits

  • Min frame ≥ 2·d·R/v (else can't detect collision before TX ends)
  • Wireless can't CD because TX deafens RX → CSMA/CA instead

Sockets count

  • UDP server with N clients: 1 socket
  • TCP server with N clients: N+1 (welcome + per-client)

ARP cross-subnet

  • If dst not in my subnet (by netmask): ARP for default gateway's MAC, not for dst
  • Switch only knows MACs; cross-LAN needs router

Formula Index

  1. End-to-end = Σ(L/R + d/v) + queue
  2. BDP = R · RTT
  3. U_SW = T_tr / (T_tr + 2·T_prop)
  4. TCP throughput = 3W/(4·RTT)
  5. CS time = max(NF/U_s, F/d_min)
  6. P2P time = max(F/U_s, F/d_min, NF/(U_s+ΣU_i))
  7. Slotted ALOHA S_max = 1/e at p=1/N
  8. CSMA/CD min frame ≥ 2·d·R/v
  9. Pathloss L = (4πdf/c)²
  10. SNR_dB = 10·log(S/N)
  11. D_x(y) = min_v {c(x,v) + D_v(y)}
  12. CRC: R = D·2^r mod G
  13. WFQ class i share = w_i / Σw_j
